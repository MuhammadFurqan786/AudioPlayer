# AudioPlayer

A clean and modern Android audio player built with **Jetpack Compose** and **Media3**.

## Features
- Play local audio files
- Modern Media3 implementation
- Jetpack Compose UI
- Playback controls (play, pause, seek, etc.)

## Tech Stack
- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Media:** Media3 (formerly ExoPlayer)
- **Architecture:** MVVM

## Getting Started
1. Clone the repository
2. Open the project in Android Studio
3. Run on an emulator or physical device
